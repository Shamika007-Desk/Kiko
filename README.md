Kiko 

I had an idea for a simple website where you can make customized digital invites with themes (like Cyberpunk or Dark Anime) and get a live RSVP link. 
I designed the basic HTML layout and features, and my friend gecko@temo35 did the heavy lifting on the coding to make it actually work. We also used Gemini AI to help us brainstorm the design requests, map out the plans, and get it all together. Just a fun, honest project built between friends and AI.
